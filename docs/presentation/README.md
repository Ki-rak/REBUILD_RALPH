# RE:Build Agent 소개 발표자료

`index.html`을 브라우저로 열면 됩니다. 글꼴·스타일·스크립트를 포함한 단일 HTML이며 외부 네트워크 요청이 없습니다.

- 구성: 문제 인식 / 아이데이션 / MD 지식화 / 과거·현재 연결과 산출물 / 향후 발전 가능성 (총 5장)
- 이동: 좌우 방향키, Page Up·Down, Home·End, 하단 번호와 이동 버튼
- 전체화면: F 키 또는 전체화면 버튼
- 상호작용: 문제 항목, 지식 연결, 문서 형식과 MD·JSON, 과거 근거와 결과물, 향후 확장 방향 선택
- 모바일: 좌우 스와이프 또는 하단 버튼으로 이동하며, 긴 내용은 세로 스크롤
- 인쇄: 인쇄 버튼 또는 Ctrl+P. 동봉한 REBuild-Agent.pdf는 5페이지 인쇄본입니다.

본문은 사용자가 제공한 문제 인식과 프로젝트의 SPEC.md·GOAL.md·docs/UX_DECISIONS.md를 바탕으로 작성했습니다. 변환·비교 내용은 발표용 설명 예시이며 실제 업로드나 제품 분석 결과가 아닙니다. 향후 구상과 현재 기능 소개를 구분했습니다.
