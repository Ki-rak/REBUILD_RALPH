## 수정 범위

생성 사본에서 본문·출처 영역을 재배치하고 읽을 수 있는 글자 크기를 유지한다. 초기 본문은 원문 기반의 제한된 발췌임을 명시하며 전체 비교와 SourceRef는 서명된 초안의 detail_text/근거 필드와 편집 가능한 발표자 노트에 보존한다. UI에서 승인 전에 상세 내용을 펼쳐 볼 수 있다.

사용자가 편집한 본문·판단·검토 의견은 표시 한도 안에서 그대로 출력한다. 한도를 넘으면 SLIDE_CONTENT_TOO_LONG 또는 SLIDE_TITLE_TOO_LONG으로 저장·승인을 거부한다. 조용한 잘림이나 읽을 수 없을 정도의 글자 축소를 하지 않는다. 한도는 한국어 줄바꿈과 실제 배치 폭을 고려해야 한다.

출력 PPTX/XLSX의 메타데이터에 정확한 제품명을 기록하되 제공 양식 파일은 변경하지 않는다. 기존 구조·내용 검증의 통과를 가독성 통과로 대신하지 않는다.

## 현재 검증 상태

수정 진행 중. 승인본에 긴 본문 편집을 시도한 신규 API 회귀는 최초 200을 반환해 실패했다. 수정 후에는 422로 거부하고 기존 승인·개정·본문이 유지되어야 한다. 기존 실패 이미지와 시험 기록은 이후 통과 기록으로 덮어쓰지 않는다.
