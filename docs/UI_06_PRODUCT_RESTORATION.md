# RE:Build Agent · UI 06 반영 및 프로젝트 관리

2026-09-22. 최신 사용자 요청에 따른 제품 변경이며 기존 UI 원본은 수정하지 않았다.

- 참조: `docs/ui-review/index.html`, `ui-v6.css`, `app-v6.js`. 흰색 220px 내비게이션, Pretendard, #245c47 녹색, 연한 민트 소개 영역, 2열 프로젝트 카드, 30px 제목과 정보 밀도를 제품에 반영했다.
- 실제 데이터/API와 3종 결과물 초안·근거·검토·승인·파일 생성 흐름을 유지했다. UI 시안의 고정 프로젝트·그래프·분석 예시는 복사하지 않았다.
- 지식 자료실은 과거 원문 ↔ 지식 항목 ↔ 신규 원문의 연결을 표시한다. 근거 없는 쪽에는 연결선을 그리지 않는다. 전체 노드·연결 근거는 펼쳐 확인하며 아래 비교에서 원문 근거를 조회한다.
- 근거 120개가 연결된 초안도 행마다 근거 수 버튼 하나로 표시하고, 원문 링크는 대화상자에 보존한다.
- 새 프로젝트의 이름 바로 아래 원본 업로드를 제공한다. 3.8MB 초과 묶음은 프로젝트 생성 요청 전에 거부하여 빈 프로젝트를 남기지 않는다.
- 프로젝트 목록과 상세에서 이름 수정·삭제를 제공한다. 삭제는 명시적 확인 후 서버에 `deleted_at`을 기록하는 방식이다. 원본·기록은 보존하고 제품 목록·검색·분석·문서/초안 직접 접근에서 제외한다. 영구 삭제와 복원 UI는 이번 변경 범위가 아니다.
- 이름 수정/삭제는 현재 version으로만 수행하고 충돌은409, 다른 사용자 접근은404다. 과거 프로젝트 변경은 관련 승인도 무효화한다. 초안에 프로젝트 version 스냅샷을 저장하고 최종 승인 서명 및 파일 생성 검증에 결합한다. 이 스냅샷이 없는 이전 초안은 새로 생성·검토·승인해야 한다.

검증 증거는 `ops/runtime/demo/ui-v6-management/report.json` 및 동일 폴더의 reference/home/project/knowledge/mobile PNG에 있다. 이것은 TEST_STORAGE_INJECTED UI/API 검증이며 실제 Supabase 통합 증거와 구분한다. 1440px에서 시안/제품을 시각 비교하고375px에서 가로 넘침 없이 관리 기능을 실행했다. 실제 Supabase 검증은 별도 통합 세션이 담당한다.
