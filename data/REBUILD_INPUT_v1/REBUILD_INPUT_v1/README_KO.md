## 가장 먼저 할 일

1. INPUT 압축파일을 풉니다.
2. 과거 자료 경로는 `01_PAST_PROJECTS`로 지정합니다.

## 데이터 해석

- 과거 관측값과 신규 설계값을 구분합니다. 지하수위는 지표 아래 깊이이며 수압이 아닙니다.
- 같은 사건의 DOCX·XLSX·PPTX·회의록은 서로 보완하는 근거이며 별도 사건 네 건이 아닙니다.
- 추가원가는 최종원가에 포함됩니다. 승인 변경금액은 수입 측 항목입니다.
- 수정번호가 높아도 미승인 문서는 유효본이 아닙니다. 승인 정정서는 명시된 변경 항목만 대체합니다.
- 빈 값은 미확정 또는 미발생입니다. 과거 P03의 배수량 0과 신규 N02의 미확정은 다른 뜻입니다.
- 공정표는 해커톤용 요약 WBS입니다. 한 달은 30일, Finish는 종료 경계일로 정의했습니다. 상세 시공 네트워크나 설계 검증 자료가 아닙니다.
- 모든 문서는 테스트를 위한 축약본이며, 수백 페이지 분량의 실무 발주도서 전체를 재현한 것은 아닙니다.
